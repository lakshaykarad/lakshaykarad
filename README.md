# Lakshay Karad

**Full-Stack Mobile Engineer — Android & Backend**

I build complete systems end to end — Android clients in Kotlin and the backend services behind them in Python. Most of my work replaces paid, rate-limited third-party APIs with self-hosted, open-source infrastructure. 15+ Android and backend projects built independently, including production-style systems with containerized deployments, authentication, and load-tested APIs.

- **Android:** Kotlin, Jetpack Compose, MVVM, Clean Architecture, Hilt, Retrofit, Coroutines/Flow, Room, WorkManager, Foreground Services
- **Infrastructure & Data:** Docker, Docker Compose, Nginx, PostgreSQL, Redis, SQLite
